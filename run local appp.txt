Now create the real instance, check it and destroy it. Do all three steps in one sitting. A t3.micro costs a fraction of a cent per hour, but don’t leave it running overnight.

1. Create it:

powershell
terraform apply

It shows the same plan and asks Enter a value:. Type yes and press Enter. It takes 30–60 seconds. At the end you get instance_id, instance_state and public_ip. Send me those three lines. They aren’t secret.

2. Check it in the AWS console:

Switch the region (top right) to Asia Pacific (Mumbai) ap-south-1.
Search for EC2 → Instances.
You should see portal-request-1 with a running state. That’s your first real instance.

3. Destroy it right away:

powershell
terraform destroy
